# Estruturas de Roteiro

> Cópia da peça `estruturas-de-roteiro/README` do método (gerada do webapp, método 9cfc1c460c97). Com o conector ligado, vale a versão de `sofia_metodo` com `estruturas-de-roteiro/README`, que é a mais nova. Não edite à mão: o arquivo é regerado.

Estruturas testadas para escrita de roteiros virais. Cada uma serve para um tipo diferente de vídeo.

## Estruturas disponíveis

| Estrutura | Etapas | Melhor para |
|---|---|---|
| AIDA | Atenção > Interesse > Desejo > Ação | Vídeos de venda, conteúdo educativo com CTA |
| IHC | Identificação > História > Conteúdo | Conexão emocional, plantar ideias sem parecer venda |
| Jeito Errado x Jeito Certo | Conflito > Erro > Virada > Acerto > Mudança | Tutoriais, posicionamento de autoridade, contraste |
| Ele, Eu, Você, Futuro | Ele > Eu > Você > Futuro | Storytelling compartilhado, narrativa que cresce |
| Análise | Conflito > Resultados > 3 Motivos > Moral | Surfar tendências, analisar criadores, posicionar método |

## Como os agentes usam estas estruturas

- O **roteirista** sugere a estrutura mais adequada ao tema e objetivo do usuário
- Na análise de um vídeo, a Sofia identifica qual estrutura um vídeo analisado está usando
- O **crítico** verifica se a estrutura escolhida foi aplicada corretamente
